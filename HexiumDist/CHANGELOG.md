# Changelog

All notable changes to **Valkyrie's Cargo** are documented here.

---

## [0.1.0] - 2026-09-07

### Initial Release
- **Valkyrie Delivery System**: Air-drop mechanic delivering Ingvar the Far-Travelled to rested players within base comfort.
- **Ingvar the Far-Travelled**: Red-bearded dwarven merchant clad in heavy plate mail carrying an ironbound trade cargo trunk.
- **Custom Cargo Terminal**: Interactive trading interface with separate wares, wants, and staging tray.
- **Dynamic Market Core**: 72 default catalogue entries (18 wares, 54 wants) with floating supply-and-demand price curves and day-length drift.
- **Barter & Economy Balance**: 800 starting coin purse limit with support for direct item barter at live valuation.
- **ServerSync & Dedicated Server Architecture**: Zero client-authoritative state, synchronized configuration lock, and world sidecar persistence (`.dat`).
- **Admin Commands**: `cargo visit`, `cargo dismiss`, and `cargo status` console controls.
