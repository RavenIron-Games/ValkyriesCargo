Storm10 log excerpt - the release session of 2026-09-11 (Valheim 1.0.12)
=======================================================================

WHERE THESE LINES COME FROM, AND WHY THIS FILE EXISTS.

BepInEx overwrites BepInEx\LogOutput.log on every boot and keeps no rotation. The server was
restarted at 09:57 that morning to clear a PlayFab transport failure, so the boot that carried
the 09:44 non-admin proof was overwritten a quarter of an hour after it was made. The proof's
own evidence was destroyed by the fix for an unrelated problem.

The 09:44 lines below are therefore copied from the session transcript, where they appear in the
output of the commands that read the live log at the time. The 09:58 and 10:01 lines below are
still in LogOutput.log on disk and can be read there directly.

THE LESSON, worth more than the excerpt: a proof that lives only in a log the next restart
overwrites is not preserved. Copy the lines into a file beside the proof document on the day,
before anything restarts.
